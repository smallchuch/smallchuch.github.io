Overview

This is a staged build of a credit-risk model on the Home Credit default dataset. Rather than jumping straight to a model, each phase is done deliberately and published as its own executive summary, so the reasoning behind every modelling choice is visible and auditable — the same standard a lending or risk function would expect.

The stages

  • Default-rate driver scan (EDA) — profiling the data, surfacing the credit characteristics that drive default, and building leakage-safe feature signal.
  • Probability of default (PD) — modelling the likelihood that a borrower defaults.
  • Loss given default (LGD) — estimating how much is lost when a default occurs.
  • Exposure at default (EAD) — estimating the outstanding exposure at the point of default.

Guarding against leakage

A large part of the groundwork went into avoiding the two mistakes that quietly inflate model performance: train/test contamination — letting information from the test set influence training decisions — and target leakage through default-rate encoding, where encoding a category by its observed default rate hands the model a peek at the outcome it is meant to predict. Both were identified and handled so every stage is evaluated honestly.
