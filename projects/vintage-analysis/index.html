Vintage Analysis — Lending Club loans

What a vintage analysis shows

A portfolio's overall default rate mixes old loans with new ones, so it can look healthy while recent lending is getting worse. A vintage analysis separates the book by origination cohort and compares each one at the same months on book, which makes changes in underwriting quality visible early.

Plan

  • Cohorts — group loans by origination quarter.
  • Curves — cumulative default rate by months on book for each cohort.
  • Comparison — line vintages up at the same age to spot deterioration or improvement.
  • Drill-down — split curves by grade and term to tie performance back to what was approved.

Data

Lending Club loan data from Kaggle: accepted loans with origination date, grade, term and payment status.
