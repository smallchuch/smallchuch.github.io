Mortgage Vintage Analysis

A reusable pipeline for analysing mortgage performance by origination cohort, including delinquency migration, default behaviour and portfolio trends.

What a vintage analysis shows

A portfolio's overall default rate mixes old loans with new ones, so it can look stable while recent lending is deteriorating. A vintage analysis groups loans by origination cohort and compares each one at the same point in its life, so changes in underwriting quality show up early.

Scope

  • Cohorts: loans grouped by origination period.
  • Delinquency migration: how loans move between delinquency buckets over time.
  • Default behaviour: default performance by cohort and months on book.
  • Portfolio trends: how newer and older cohorts compare across the book.

Data

Freddie Mac mortgage performance data.
